# SIMA Pay — Telegram Mini App

Порт iOS-прототипа (SwiftUI) на веб: тот же UI, та же логика, шрифты Inter и логотип.
Открывается внутри Telegram как Mini App; вне Telegram тоже работает (Face ID заменяется симуляцией).

## Экраны

| Экран | Файл | Что делает |
|---|---|---|
| Home | `index.html` → `#screen-home` | Логотип, пустое состояние или список карт с лейблом «Aktiv» и кнопкой удаления |
| Add card | `#screen-add` | Ввод номера/срока/CVV с форматированием и живым превью карты |
| Biometric | `#screen-bio` | Распознавание лица через Telegram → карта становится активной |

## Структура

```
telegram-miniapp/
├── index.html      # разметка трёх экранов + SVG-иконки
```

## Деплой (автоматический)

Приложение хостится на GitHub Pages репозитория **Ceyhun1222/myproject**:
ветка `master`, корень репозитория, Pages → *Deploy from a branch → master / (root)*.
**Любой пуш в `master` автоматически пересобирает сайт** (обычно меньше минуты), отдельный workflow не нужен.

Выкатить текущую версию из этой папки:

```bash
bash scripts/deploy-miniapp.sh "что изменилось"
```

Скрипт: синхронизирует `telegram-miniapp/` с корнем репозитория (лишние файлы удаляет),
коммитит и пушит по SSH-ключу `~/.ssh/simapay_github` через `ssh.github.com:443`
(порт 22 в этой сети закрыт). Если изменений нет — ничего не делает.

Кэш: GitHub Pages отдаёт HTML с `Cache-Control: max-age=600`, поэтому новая версия может
появиться в Telegram с задержкой до ~10 минут. Чтобы увидеть сразу — полностью закройте
мини-апп (свайп вверх) и откройте снова.

## Подключение к Telegram

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username.
2. Создайте Mini App: `/newapp` → выберите бота → название → иконку (можно пропустить) → GIF (пропустить) → **URL прода** → short name.
3. Либо проще: `/setmenubutton` → бот → вставьте URL — приложение откроется кнопкой меню бота.
4. Откройте бота и нажмите кнопку меню.

## Биометрия

- **В Telegram (iOS, Bot API 7.2+):** настоящий Face ID / Touch ID через `WebApp.BiometricManager`
  (`init → requestAccess → authenticate`). При первом запуске Telegram спросит разрешение.
- **В обычном браузере или старом клиенте:** Face ID недоступен, показывается подсказка и симуляция 1.5 с.
- **На устройствах без биометрии (Telegram Desktop, веб-версия):** вместо ошибки — подсказка и та же симуляция, чтобы демо проходило на любом устройстве. Отказ пользователя в диалоге Face ID показывается как ошибка.
- Шаг сканирования ладони убран: после ввода данных карты сразу открывается распознавание лица.
- **Камера:** при входе на экран биометрии открывается фронтальная камера в вертикальном овале
  (как в SIMA Imza): зеркальное превью через `getUserMedia`, затемнение вне овала, линия сканирования
  во время проверки. Если камера недоступна или доступ запрещён — статичная заглушка и подсказка.
  Поток камеры останавливается при уходе с экрана или после успешной активации.

## Удаление карты

На каждой карточке в списке — кнопка с корзиной (справа сверху). По нажатию показывается подтверждение:
нативный диалог Telegram (`WebApp.showConfirm`) внутри Telegram, `window.confirm` в браузере.
После подтверждения карта убирается из списка и из `localStorage`; если карт не осталось, возвращается пустое состояние.

## Языки

Приложение двуязычное: азербайджанский (AZ) и русский (RU). Переключатель — в шапке главного экрана.
Выбор сохраняется в `localStorage`; при первом запуске язык берётся из профиля Telegram
(`initDataUnsafe.user.language_code`): русский → RU, иначе AZ.

Все строки интерфейса, включая диалоги подтверждения и системные подсказки Face ID, лежат в одном
словаре `STRINGS` в начале `app.js`. Чтобы добавить третий язык — добавьте ключ в `STRINGS`,
кнопку `data-lang` в `#lang-switch` и разрешите его в `setLanguage`.

## Хранение данных

Карты (маскированные) хранятся в `localStorage` устройства. Для продакшена нужно:
серверная валидация и токенизация карты (PCI DSS), а для «облачной» синхронизации —
`WebApp.CloudStorage`. Сейчас приложение полностью клиентское и не отправляет данные наружу.

## Отличия от iOS-версии

- Нет нативных анимаций SwiftUI и App Store-дистрибуции.
- `NavigationStack`/`sheet` заменены на переключение секций + нативная кнопка «Назад» Telegram.
- Хаптика — через `WebApp.HapticFeedback`.
